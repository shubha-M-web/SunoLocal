System Architecture
  • Frontend: Clean responsive HTML5/CSS3 using modern SaaS aesthetics, Bootstrap 5 components, and vanilla JavaScript Web Speech API for zero-latency client-side speech synthesis.
  • Backend (Flask): Lightweight, beginner-friendly modular Python backend with dedicated intelligence modules.
  • Database (SQLite): Relational schema with users, user_preferences, opportunities, saved_opportunities, and recently_viewed tables utilizing parameterized queries to prevent SQL injection.
  • Modular Design: Modules for ranking (recommender.py), summarization (summarizer.py), and TrustCheck (trustcheck.py) are separated from HTTP routing for clean extensibility.
Transparent AI & Algorithms
  • Transparent Recommendation Scoring: Score = Interest Match (50%) + Geographic Proximity (30%) + Urgency/Timeliness (20%). Includes human-readable explanations rather than opaque black-box scores.
  • AI Summarizer with Reliable Fallback: If an LLM API key (e.g. GEMINI_API_KEY) is provided, calls the generative API. If absent, seamlessly falls back to a deterministic, zero-hallucination rule-based extractive engine that organizes notifications into 6 standardized questions in English and Kannada.
  • TrustCheck Integrity Engine: Audits domain extensions (validating official .gov.in, .ac.in, .res.in), flags missing URLs, calculates deadline countdowns, and displays clear warnings.

Web Speech API Voice Engine & Kannada (kn-IN) Guide

Browser Speech Synthesis Standards • Rule 9 & 10 Compliance
Strict Voice Matching

SunoLocal checks available voices using speechSynthesis.getVoices() and handles asynchronous loading via the voiceschanged event. If a native Kannada (kn-IN) voice is not detected on the device, SunoLocal never silently reads Kannada text using an English voice, preventing broken silence.

Best Experience: Microsoft Edge

Microsoft Edge comes with cloud-backed natural neural voices pre-configured for Indian regional languages, including Microsoft Gagan Online (Natural) - Kannada (India) and Microsoft Sapna. Simply opening SunoLocal in Edge provides instant, high-quality Kannada audio out-of-the-box.

Enabling on Windows & Chrome

On Windows 10/11, go to Settings → Time & Language → Language & Region → Add a language. Search for Kannada (ಕನ್ನಡ) and check the Text-to-speech pack. Once installed, both Chrome and Windows desktop apps gain offline Kannada TTS capabilities.

Expected Social Impact for Karnataka

Empowering First-Gen Students

Many students in Mysore, Mandya, and rural Karnataka are first-generation college attendees whose parents cannot help decipher complex official scholarship gazettes. Audio summaries bridge the literacy barrier.

Combating Scam Forwards

Social media forwards asking for spot registration fees at bus stands or fake recruitment centers trick desperate job seekers. SunoLocal TrustCheck equips students with critical source verification habits.

Tier-2 Tech Cluster Growth

With Karnataka's "Beyond Bengaluru" initiative growing the Mysuru IT and ESDM cluster, SunoLocal directly connects local students to high-value apprenticeships and skill bootcamps close to home.
